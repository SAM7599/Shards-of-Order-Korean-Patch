# Shards of Order 비공식 한국어 패치 (기계번역)

`Shards of Order`를 한국어로 플레이할 수 있도록 만든 비공식 한국어 패치입니다.

## 한국어 지원 범위

- 전체 대사 5,648줄 번역
- UI 및 주요 시스템 문구 번역
- 게임 진행에 필요한 선택지, 설명문, 아이템/효과 관련 문구 번역
- 한글 표시를 위한 전용 글꼴 포함

현재 패치는 게임 내 `简体中文` 언어 데이터를 한국어로 교체하는 방식입니다.  
게임에 한국어 언어 항목이 따로 추가되는 것은 아니며, 설치 후 언어를 `简体中文`으로 선택하면 한국어로 표시됩니다.

## 번역 방향

- 문장을 직역하기보다 한국어로 자연스럽게 읽히는 것을 우선했습니다.
- 게임의 분위기와 캐릭터 말투를 최대한 유지하려고 했습니다.
- 용어는 플레이 중 헷갈리지 않도록 일관성을 우선했습니다.
- 일부 문장은 원문의 뉘앙스를 살리기 위해 의역이 포함되어 있습니다.

## 간편 설치 프로그램

패치에는 별도의 설치 프로그램이 포함되어 있습니다.

- 게임 설치 경로 자동 탐색
- 직접 폴더 선택 가능
- 원본 파일 자동 백업
- 패치 적용
- 원본 복구 기능 제공
- 게임 버전 불일치 감지 시 경고 표시

일반 사용자는 간편 설치 프로그램 사용을 권장합니다.

## 설치 방법

1. 압축 파일을 원하는 위치에 풉니다.
2. `한국어패치_설치.vbs`를 실행합니다.
3. 관리자 권한 요청 창이 나오면 `예`를 누릅니다.
4. 설치 프로그램이 게임 폴더를 자동으로 찾습니다.
5. 경로가 맞는지 확인한 뒤 `패치 설치`를 누릅니다.
6. 설치가 완료되면 게임을 실행합니다.
7. 게임 설정에서 언어를 `简体中文`으로 변경합니다.

## 수동 설치 방법

수동 설치는 게임 파일을 직접 교체해야 하므로 권장하지 않습니다.  
가능하면 위의 간편 설치 프로그램을 사용해 주세요.

수동으로 적용하려면 압축 파일 안의 `data` 폴더에 있는 패치 파일을 게임 설치 폴더에 직접 반영해야 합니다.

기본 경로 예시:

```text
Steam\steamapps\common\ShardsOfOrder\ShardsOfOrder
```

교체 대상:

- ShardsOfOrder_Data\sharedassets0.assets
- ShardsOfOrder_Data\sharedassets4.assets
- ShardsOfOrder_Data\StreamingAssets\aa\StandaloneWindows64\localization-string-tables-chinese(simplified)(zh-hans)_assets_all.bundle

주의: 글꼴 이미지 데이터도 함께 적용되어야 하므로 단순 파일 복사만으로는 정상 표시되지 않을 수 있습니다.
수동 설치가 필요한 경우에도 `SOO_KoreanPatch.ps1`을 직접 실행하는 방식을 권장합니다.

## 원본 복구

설치 프로그램에서 `원본으로 되돌리기` 버튼을 누르면 패치 설치 시 백업한 원본 파일로 복원할 수 있습니다.
백업 폴더가 없거나 복원에 실패한 경우에는 Steam에서 아래 기능을 사용해 주세요.

Steam 라이브러리 → Shards of Order 우클릭 → 속성 → 설치된 파일 → 게임 파일 무결성 확인

이 기능을 실행하면 Steam이 원본 파일을 다시 내려받아 복구합니다.

## 참고 및 주의사항

- 이 패치는 비공식 팬 패치입니다.
- 게임 업데이트 후에는 패치가 정상 작동하지 않을 수 있습니다.
- 패치 전 게임을 완전히 종료해 주세요.
- 다른 모드나 파일 수정이 적용되어 있다면 충돌할 수 있습니다.
- 설치 중 버전 불일치 경고가 나오면 게임 업데이트 여부를 먼저 확인해 주세요.
- 문제가 생기면 원본 복구 또는 Steam의 게임 파일 무결성 확인을 이용해 주세요.

## 영상 및 방송 이용
이 한국어 패치를 적용한 상태로 영상, 방송, 스트리밍, 리뷰 콘텐츠를 제작해도 괜찮습니다.
별도의 허락 없이 사용해도 되며, 가능하다면 패치 배포 페이지를 함께 소개해 주시면 다른 플레이어들에게도 도움이 됩니다.
단, 이 패치는 비공식 팬 패치이므로 게임 자체의 저작권은 원 개발사 및 배급사에 있습니다.
