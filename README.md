# Shards of Order 비공식 한국어 패치 1.0 배포
안녕하세요.
`Shards of Order`를 한국어로 플레이할 수 있는 비공식 한국어 패치를 배포합니다.
중국어 간체 언어 데이터를 기반으로 제작했으며, 단순 기계 번역에서 어색하게 보이는 문장과 게임 용어를 최대한 자연스럽게 다듬었습니다.
### 주요 패치 내용
- 메인 메뉴 및 설정 화면 한국어화
- 카드 이름과 카드 설명 한국어화
- 전투 안내 및 튜토리얼 한국어화
- 스토리와 선택지 한국어화
- 캐릭터 대사를 자연스러운 반말 대화체로 교정
- 서술 및 시스템 안내 문체 통일
- 임무 기록 169개 항목 번역 및 문장 개선
- 백과사전과 게임 용어 한국어화
- 한국어 글꼴 적용
- 한국어 설치 및 원본 복구 프로그램 제공
- 스토리가 중요한 게임인 만큼 등장인물의 말투, 선택지, 장면의 흐름이 자연스럽게 이어지도록 중점적으로 수정했습니다.
### 설치 방법
- 아래 링크에서 한국어 패치 ZIP 파일을 내려받습니다.
- 내려받은 ZIP 파일의 압축을 완전히 해제합니다.
- 게임이 실행 중이라면 종료합니다.
- 압축을 푼 폴더의 Setup.exe를 실행합니다.
- 관리자 권한 요청이 나오면 허용합니다.
- 설치 프로그램에서 한국어 패치 설치를 누릅니다.
- 진행률이 100%가 될 때까지 기다립니다.
- 게임을 실행한 뒤 언어 설정에서 **중국어 간체(简体中文)**를 선택합니다.
별도의 프로그램이나 런타임을 설치할 필요는 없습니다.
ZIP 안의 파일들은 모두 같은 폴더에 있어야 합니다.
### 원본으로 복구하는 방법
- 패치 설치에 사용한 Setup.exe를 다시 실행한 뒤 원본 복구 버튼을 누르면 됩니다.

### 주의사항
- 공식 한국어 번역이 아닌 비공식 팬 번역입니다.
- 원문의 의미를 유지하면서 자연스러운 한국어를 위해 일부 문장을 의역했습니다.
- 아직 발견하지 못한 오역이나 어색한 문장이 있을 수 있습니다.
- 게임 업데이트 이후에는 패치가 정상적으로 작동하지 않을 수 있습니다.
- Steam에서 파일 무결성 검사를 실행하면 패치가 원본으로 돌아갈 수 있습니다.
- 설치와 복구를 진행할 때는 반드시 게임을 종료해 주세요.
- 패치 파일을 유료로 판매하거나 유료 회원에게만 배포하는 행위는 금지합니다.
### 방송 및 영상 제작
- 이 패치를 적용한 게임의 영상 제작과 실시간 방송은 자유롭게 가능합니다.
- YouTube 및 Twitch 등의 광고 수익, 구독과 후원 기능도 이용할 수 있습니다. 가능하다면 영상 설명란에 한국어 패치의 출처를 남겨 주세요.
- 단, 게임 영상과 방송에 관한 최종 이용 기준은 게임 개발사와 배급사의 정책을 따릅니다.
### 오류 제보
- 오역, 번역이 깨지는 현상, 게임 종료 또는 설치 오류를 발견하면 다음 내용을 함께 남겨 주세요.
- 문제가 발생한 화면의 스크린샷
- 문제가 발생한 위치 또는 임무 이름
- 오류가 발생하기 직전에 진행한 행동
- 사용 중인 패치 버전
- 제보해 주신 내용은 이후 패치 개선에 반영하겠습니다.
