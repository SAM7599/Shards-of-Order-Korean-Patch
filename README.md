# Shards of Order 한국어 패치
중국어 간체 언어 데이터 기반으로 제작한 비공식 한국어 패치입니다.

## 설치 방법

1. 첨부된 ZIP 파일을 내려받아 압축을 풉니다.
2. 게임을 종료합니다.
3. Setup.exe를 실행합니다.
4. 한국어 패치 설치 버튼을 누릅니다.
5. 게임 설정에서 중국어 간체(简体中文)를 선택합니다.

## 주의사항

- 게임 업데이트 후 패치가 작동하지 않을 수 있습니다.
- Steam 파일 무결성 검사를 하면 원본으로 복구될 수 있습니다.
- 공식 번역이 아닌 비공식 팬 번역입니다.
