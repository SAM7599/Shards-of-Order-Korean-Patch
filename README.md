# Shards of Order 비공식 한국어 패치

`Shards of Order`를 한국어로 편하게 즐길 수 있도록 제작한 비공식 한국어 패치입니다.

메인 메뉴와 설정 화면부터 카드, 전투 안내, 스토리, 선택지, 임무 기록, 백과사전까지 게임의 주요 텍스트를 한국어로 번역했습니다.

단순히 문장을 한국어로 바꾸는 데 그치지 않고, 등장인물의 말투와 장면의 흐름을 고려해 자연스럽게 읽을 수 있도록 다듬었습니다.

## 한국어 지원 범위

- 메인 메뉴 및 설정 화면
- 스토리와 캐릭터 대사
- 대화 선택지
- 카드 이름과 카드 설명
- 전투 안내와 튜토리얼
- 임무 제목과 임무 기록
- 백과사전
- 상태 효과 및 주요 게임 용어
- 시스템 메시지와 알림

## 번역 방향

스토리가 중요한 게임인 만큼 문맥과 분위기를 살리는 데 중점을 두었습니다.

- 캐릭터 대사는 자연스러운 대화체로 번역
- 서술과 시스템 안내는 읽기 쉬운 문어체로 통일
- 어색한 직역과 기계 번역 표현 개선
- 앞뒤 문맥이 맞지 않는 문장 교정
- 선택지를 짧고 이해하기 쉽게 정리
- 등장인물 이름과 주요 게임 용어 통일
- 필요한 경우 원문의 뜻을 유지하는 범위에서 자연스럽게 의역

## 한국어 글꼴 지원

게임의 여러 화면에서 한글이 정상적으로 표시되도록 전용 한국어 글꼴 패치를 포함했습니다.

메뉴뿐만 아니라 다음 화면에서도 한국어를 정상적으로 표시할 수 있습니다.

- 공지사항
- 스토리와 대사
- 카드 이름과 설명
- 임무 기록
- 백과사전
- 전투 안내

## 간편 설치 프로그램

게임 파일을 직접 찾아서 덮어쓸 필요 없이 전용 설치 프로그램으로 패치를 적용할 수 있습니다.

- 한국어 설치 화면 제공
- 게임 설치 경로 자동 검색
- 설치 진행률 표시
- 원본 파일 자동 백업
- 원본 복구 기능 제공
- 별도 프로그램이나 런타임 설치 불필요

## 설치 방법

1. [Releases](../../releases/latest)에서 최신 한국어 패치를 내려받습니다.
2. 내려받은 ZIP 파일의 압축을 완전히 해제합니다.
3. 게임이 실행 중이라면 종료합니다.
4. 압축을 푼 폴더에서 `Setup.exe`를 실행합니다.
5. 관리자 권한 요청이 나오면 허용합니다.
6. **한국어 패치 설치** 버튼을 누릅니다.
7. 진행률이 100%가 될 때까지 기다립니다.
8. 게임을 실행하고 언어 설정에서 **중국어 간체(简体中文)**를 선택합니다.

> 이 패치는 중국어 간체 언어 슬롯을 한국어로 교체합니다.

## 원본 복구

패치를 제거하고 싶다면 `Setup.exe`를 다시 실행한 뒤 **원본 복구** 버튼을 누르면 됩니다.

백업 파일이 없거나 정상적으로 복구되지 않는 경우에는 Steam의 게임 파일 무결성 검사를 이용해 주세요.

## 참고 및 주의사항

- 공식 번역이 아닌 비공식 팬 번역입니다.
- 자연스러운 한국어 표현을 위해 일부 문장은 의역했습니다.
- 번역되지 않았거나 어색한 문장이 일부 남아 있을 수 있습니다.
- 설치와 복구를 진행하기 전에는 반드시 게임을 종료해 주세요.
- Steam 파일 무결성 검사를 실행하면 한국어 패치가 제거될 수 있습니다.
- 게임 업데이트 이후 패치가 정상적으로 작동하지 않을 수 있습니다.
- 패치 파일을 판매하거나 유료 회원에게만 제공하는 행위는 금지합니다.

## 영상 및 방송 이용

이 한국어 패치를 적용한 게임의 영상 제작과 실시간 방송은 자유롭게 할 수 있습니다.

YouTube 및 Twitch 등에서 제공하는 광고 수익, 구독과 후원 기능도 이용할 수 있습니다. 가능하다면 영상 설명란에 한국어 패치의 출처를 남겨 주세요.

게임 영상과 방송에 관한 최종 이용 기준은 게임 개발사와 배급사의 정책을 따릅니다.

## 오류 및 번역 제보

오역, 어색한 문장, 글자 깨짐 또는 설치 오류를 발견했다면 [GitHub Issues](../../issues)에 제보해 주세요.

제보할 때 다음 정보를 함께 남기면 문제를 확인하는 데 도움이 됩니다.

- 사용 중인 한국어 패치 버전
- 문제가 발생한 화면의 스크린샷
- 임무 또는 지역 이름
- 오류가 발생하기 직전에 진행한 행동

> Steam 계정명이나 Windows 사용자 이름 등 개인정보가 보이는 부분은 가린 뒤 첨부해 주세요.
